# AuMDS — Reference HTML Animation Implementation

This version implements the animation patterns from the supplied ScrollCraft/reference HTML as a reusable layer on the AuMDS pages.

## Implemented reference-style patterns
- 3D depth + perspective scroll movement
- Scroll-triggered clip-path/portal reveals
- Kinetic word-by-word heading entrance
- 3D folding/progressive journey steps
- Layered/staggered 3D service-card stack
- Parallax depth for visual/orbit elements
- Scroll progress indicator
- Existing Three.js particle/3D hero retained
- Reduced-motion accessibility fallback
- Responsive behavior for touch/mobile

## Where they are used
- Home: hero 3D universe, depth/parallax, kinetic headings, statement reveal, service layers, journey progress
- About: kinetic headings, portal/depth visual treatment, values reveal, journey folding/progress
- Solutions: 3D service stack, clip reveals, kinetic headings
- Careers: depth/parallax, card stack, reveal animations
- Contact: split/clip reveal, kinetic heading and depth motion

## Run
Open `AuMDS_website_redesign/aumds_v2/index.html` with VS Code Live Server.

No npm install is required.
