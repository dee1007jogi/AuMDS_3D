# AuMDS Animation Upgrade

Implemented across the AuMDS redesign pages:

- Cinematic page loader and page-to-page fade transitions
- Scroll progress indicator
- Scroll reveal animations using IntersectionObserver
- Hero entrance choreography
- Animated Three.js particle/geometry universe on the home hero
- Floating orbit/core motion and ambient rings
- 3D hover tilt on service, highlight and glass cards
- Magnetic CTA interactions
- Interactive service cards with keyboard focus support
- Animated career orb and depth effects
- Scroll-linked parallax/depth motion
- Form focus micro-interactions
- Desktop custom cursor with hover expansion
- Responsive/mobile-safe motion
- `prefers-reduced-motion` accessibility support
- No extra animation framework required

Files added:
- `motion.css`
- `motion.js`

Existing HTML/CSS/JS and content are preserved, with the animation system layered on top.
