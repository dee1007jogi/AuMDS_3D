# AuMDS — 3D Redesign

> **Co-creating the Universe of Brands**  
> An immersive, state-of-the-art 3D interactive web ecosystem built with Three.js, React Three Fiber, Framer Motion, and Tailwind CSS.

---

## ✨ Features

- **🌌 3D Interactive Cosmic Canvas**: Custom shaders, planetary orbits, particle fields, and real-time lighting with React Three Fiber & Three.js.
- **⚡ Meteor Forging Emblem & Journey**: Dynamic 3D forge simulation representing high-growth brand evolution.
- **🌲 Mystic Forest & 🌊 Water World**: Immersive narrative sections featuring real-time interactive physics and audio feedback.
- **💎 Multi-Dimensional Solutions Matrix**: Filterable, categorised grid of enterprise AI, branding, and digital transformation solutions.
- **✨ Fluid Micro-Interactions**: Magnetic glow buttons, rock-gold text textures, custom physics-driven cursor, smooth Lenis inertia scrolling.
- **📱 Fully Responsive & Fast**: Optimized asset loading, glassmorphic HUD telemetry, accessible contrast, and smooth 60fps animations.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: Framer Motion, Lenis Smooth Scroll
- **Styling**: Tailwind CSS, PostCSS, Custom Design Tokens
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/dee1007jogi/AuMDS_3D.git
cd AuMDS_3D

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Typecheck & build bundle
npm run build

# Preview build locally
npm run preview
```
