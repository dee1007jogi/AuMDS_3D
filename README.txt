AuMDS 3D Redesign — Internship Submission
===========================================

What this package contains
- Multi-page responsive website: Home, About, Services, Careers, Contact, Privacy, Terms
- Pure HTML/CSS/JS (no build step required)
- Company logo included in assets/company-logo.png
- 3D-style hero ecosystem using CSS perspective, orbiting rings and pointer interaction
- Interactive capability ecosystem
- 3D tilt cards
- Dark/light mode
- Mobile navigation
- Scroll reveal animations
- Interactive case-study modals
- Consultation/contact CTA and mailto enquiry flow

Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html → Open with Live Server.

Important production notes
- Replace/verify the logo asset if the official brand asset has a newer version.
- Replace placeholder visual treatments with approved company photography, team photos, service imagery and project screenshots.
- Keep Privacy Policy and Terms of Use legally approved; the redesign currently uses audit summaries for those pages.
- The current public website uses 2025 footer text and older 2022 legal-policy revisions; verify all dates before production.
