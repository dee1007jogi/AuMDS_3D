# AuMDS — 3D Aesthetic Redesign

A responsive, working multi-page redesign concept for AuMDS (Au Multidimensional Solutions Pvt. Ltd.).

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Use Live Server on `index.html`, or open it directly in a browser.

## Pages
- index.html — immersive 3D landing page
- about.html — company story / values
- services.html — solutions universe
- careers.html — roles + application flow
- contact.html — working enquiry form
- privacy.html — redesigned legal shell + official policy link
- terms.html — redesigned legal shell + official terms link

## Interactions
- Three.js particle universe + wireframe 3D object
- Pointer-responsive 3D scene
- Interactive service cards + detail panel
- Mobile responsive navigation
- Career/contact forms prepare mailto enquiries
- Smooth scrolling and entrance loader

## Important
The visual language is a redesign concept. Replace placeholder/generated visual treatments with AuMDS-approved brand photography, logos, project imagery and case studies before production deployment.

Source content basis: the current AuMDS website and the supplied content audit.
